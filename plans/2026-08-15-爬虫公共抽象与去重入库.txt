# 2026-08-15 爬虫公共抽象 / 重试 / start_time / 验证码增强 / 去重入库

目标: 解决 ali 图片下载无重试、start_time 恒 null、验证码漏检(滑块 DOM)、两爬虫重复代码、
并落地单表 PostgreSQL 去重入库。所有决策经与用户逐项确认。

## 一、决策记录

| 主题 | 决策 |
|------|------|
| 下载重试 | 每张图最多 3 次,失败退避 1/2/4s;三次仍失败跳过不中断 |
| start_time | 从阿里列表页解析(XPath 见 docs/初步信息.txt 第59行),格式 `08月15日 10:00` → 补当年 |
| 临界提醒 | 解析时间落在 12-31 23:55~24:00 打印接近临界提醒 |
| 验证码检测 | 列表页+子页都加;URL 判定 + DOM 判定 `#nc_1__scale_text` / `#nc_1_nz1` |
| 等待策略 | 登录/断网每 5 分钟自动 goto 刷新;滑块未解随机 5-10 分钟刷新提示人工 |
| 公共抽象位置 | utils/ 放工具(parsing/browser/download),带类型注解;src/ 放正式模块 |
| models 位置 | 顶层 models/ 独立目录,不放 src |
| 建表脚本 | 放 scripts/init_db.py |
| 表设计 | 单表 listings:核心列 + UNIQUE(source,item_id) + data JSONB 承载资源字段 |
| DB 连接 | .env 配 DATABASE_URL(postgresql+psycopg2),密码由用户填 |

## 三、表设计

```sql
CREATE TABLE listings (
    id            BIGSERIAL PRIMARY KEY,
    source        VARCHAR(16)  NOT NULL,             -- gpai / ali
    item_id       VARCHAR(64)  NOT NULL,
    category      VARCHAR(32),                        -- 仅 ali(住宅/商业/工业/其他)
    title         TEXT,
    url           TEXT,
    start_price   NUMERIC(18,2) DEFAULT 0,
    ref_price     NUMERIC(18,2),
    ref_price_type VARCHAR(32),
    start_time    TIMESTAMP,
    status        VARCHAR(32),
    crawled_at    TIMESTAMP,
    data          JSONB NOT NULL DEFAULT '{}',        -- images/raw/资产路径/voice/video 路径
    created_at    TIMESTAMP DEFAULT now(),
    updated_at    TIMESTAMP DEFAULT now(),
    UNIQUE (source, item_id)
);
```

- 入库失败不应阻塞采集:try/except 记 error,DB 不可用则纯文件模式继续
