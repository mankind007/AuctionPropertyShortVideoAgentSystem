# promo-image 法拍房宣传海报合成

逐张房源图合成宣传海报,并写库。

## 触发场景

- 用户要求给某套房源生成带话术的宣传图
- 需要批量为多套房源合成海报
- 下游视频脚本技能需要已填充话术的素材

## 使用方式

### 人工直接运行(CLI)

```bash
# 单套
python skills/promo-image/scripts/compose.py --source gpai --item-id 52885

# 批量(前5套, 已生成则跳过)
python skills/promo-image/scripts/compose.py --all --limit 5

# 批量强制重生成(话术/模板改动后)
python skills/promo-image/scripts/compose.py --source ali --all --limit 1000 --force

# 指定输出宽度(默认自动取该房源图片最大宽度)
python skills/promo-image/scripts/compose.py --source gpai --item-id 52885 --width 1080
```

### Agent 调用

```python
import sys; sys.path.insert(0, ".")
from skills.promo_image.scripts.compose import run, run_all

run("gpai", "52885")           # 单套
run_all(source="gpai", limit=5) # 批量
```

## 数据契约

- 输入:房源在 DB 中已采图(`data.images` 非空)
- 输出:
  - 磁盘: `assets/{source}/{item_id}/imgs/poster_{nn}_v.png`(竖版 9:16)、`poster_{nn}_h.png`(横版 16:9)
  - DB: `data.script` = 完整口播稿; `data.script_images` = `[{file, copy, angle, source_img, orientation}]`
- 话术模板来源: `assets/短视频宣传话术.csv`

## 合成逻辑

- **双版式**:每套房源每张原图各生成一张竖版(9:16)和一张横版(16:9),适配不同平台
- **统一尺寸**:每套房源所有海报共用同一 canvas,**不硬编码**——竖版宽=原图最大宽、高=宽×16/9;横版高=原图最大高、宽=高×16/9;再叠加上下标题/话术带(由字体度量推导)
- **标题带**:顶部,**水平+垂直居中**,过长则按字符宽度自动**换行**(竖版窄更易爆行,字号自适应缩小保证图片区下限);字体 `assets/fonts/江城律动圆.ttf`;**标题显示前经 `_clean_title` 剥离拍次标签(【一拍】等)与括号注释(【…】[…]〔…〕, 含未闭合截断)**
- **少图保底**: 1 图→重复 4 次 `[A,A,A,A]`; 2 图→`[A,A,B,B]`(用户指定); ≥3 图原样。每张海报配不同角度话术(首=开场钩子, 末=行动号召, 中间按序), 保证视频时长
- **画布宽上限** `MAX_CANVAS_W=1920`: 超大原图(如 4096px)等比缩小, 避免 ffmpeg 多路解码爆内存
- **图片带**:中部,原图按 **cover** 填满整个图片带(居中裁剪溢出, 不留白);竖版用此分层布局
- **横版 16:9 特殊布局(满版)**: 因 16:9 高度有限, 若分层会让原图变成细条 → 改为**原图铺满整张画布(cover)**, 仅在**顶部标题带 / 底部话术+联系带**叠加半透明白底(透明度 ~205/255), 既保证原图占满全屏, 又保证文字可读
- **话术带**:底部,**水平居中**,按字符宽度自动换行;字体 `assets/fonts/极影毁片圆.ttf`
- **字号自适应**:标题/正文字号随画布宽放大,**标题字号恒大于正文**(缩小时下限=正文+4)
  - 竖版(1000):标题 `宽/16`(~62)/ 正文 `宽/26`(~38)
  - 横版(1778)满版:底部不应占原图一半 → 标题 `宽/20`(~89)/ 正文 `宽/34`(~52), 话术带 padding 24、联系带更小, 使底部白带仅占画布 ~30%
- **标点清理**:填充后文本经 `_clean_text` 处理——合并连续标点(`,，`→`,`、`：；`→`：`)、去行首空占位符产生的标点、去中文字案内多余空格、去句尾逗号族(`，、；：`),**保留句末正常！？。**(不误删)
- **话术填充(宽松+随机, `fill_templates`)**: 每个角度按优先级收集候选行,再用房源 item_id 作种子的稳定随机取一(同一房源再生成结果一致):
  1. **全填行**: 所有占位符均可填 → 直接采用;
  2. **宽松行**: 过半占位符可填 → 采用但**含未填占位符的整段按标点切段删除**(如「最近医院{距离}米、」整段删, 避免"最近医院米");
  3. **固定行**: 无占位符兜底行。
  CSV 中「宽松填充」列标 `否` 的**断言行**(如"中间楼层": 楼层值缺一即不成立, 1 层说"不高不低"会误导)只允许全填。无折扣(起拍=评估价)时「10折/立省≤0」句式自动跳过。
- **联系/法务信息(需求待解决项)**:图片下方空间足够时,在**左下角**以小字标注投资/法律咨询公司、电话、邮箱(4 行,见 `CONTACT_LINES`);不与居中话术重叠
- **图↔文案分配**:首图=开场钩子(吸睛),末图=行动号召(收尾),中间按逻辑序(硬指标→价格→地段→常见误区→风险→紧迫感)循环分配给各张图;图数>角度数则回卷,不截断

## 注意事项

- 话术模板来源 `assets/短视频宣传话术.csv`;新增列「宽松填充」:默认 `是`(允许过半填),`否` 表示断言行只允许全填
- 源数据清洗(`extract_fields`): 标题去拍次标签/括号注释(`【】【】〔〕`含未闭合截断)/"位于·坐落于"前缀/≥6位超大㎡残段;坐落去括号注释并过滤"调查情况/以…为准/详见"等残句、剥尾部`,XX区`式截断残段;金额统一转万元;POI 距离统一归一为**纯米数**(修掉"712m米"、"最近医院=药店"类问题);**建筑面积**优先取`建筑面积_合计`、超100万㎡垃圾值置空、**单价<0.005万/㎡置空**(防"单价0.00万/㎡")
- 派生占位符: `{折扣率}` = 起拍/参考×10; `{单价}` = 起拍元/建筑面积/1e4; `{省额}` = 参考-起拍; POI 距离 = 各分类 min(distance), 医院/学校/商场按语义子类(综合医院/小学/购物中心)优先
- `poster_*.png` 写入 `imgs/` 目录,沿用 `data.images[].file` 约定(仅存文件名)
- 批量 `--all` 幂等:已生成 `script_images` 的房源默认跳过,**`--force` 强制重生成**(话术/模板改动后需 `--force` 重跑)
